# TestingF: Claude Code dev workbench
Reverse-engineer or adopt open-source code, adapt it, build it, test it, plus a lab for skills and
workflow automations. Open a cloud session on this repo at claude.ai/code and ask, e.g.:

- "Find an open-source Python library for parsing PDFs invoices, vet it, and vendor the best one."
- "Recon vendor/foo: map its architecture and tell me how auth works."
- "Adapt vendor/foo's exporter into projects/invoice-tool with tests."
- "Create a skill in lab/skills/triage and eval it."
- "Build a workflow in lab/workflows/drive-digest and dry-run it on fixtures."

See CLAUDE.md for the rules Claude follows here.
